# 诺拉 | AI 人格工坊 v1.2

> 说句话，10 分钟造一个属于你的 AI 伙伴。

## 装完即用

安装后，对你的 AI 说：

> 「给我的 AI 加点性格」/ 「make my AI friendlier」/ 「我要一个毒舌助手」

AI 会主动带你走完创建流程。即使你什么都不说，AI 也会在下次会话**主动提议**创建人格。

## 核心机制

**双模式自动切换：** AI 根据你的输入内容自动判断应该用闲聊模式还是工作模式。

- 🍰 闲聊：亲切、有温度、带 emoji
- 🛡️ 工作：精准、高效、专业排版

## 生成后你会得到

```
你的 workspace/
├── SOUL.md          # 🧠 人设文件（双模式 + 触发词 + 约束）
├── IDENTITY.md      # 📋 身份概要
└── AGENTS.md        # 📖 行为准则（记忆管理、群聊规则…）
```

## 修改人格

随时说：

- 「改一下 AI 的名字」
- 「调整闲聊风格」
- 「加一个工作触发词」

AI 会直接编辑对应文件，不用重新走一遍流程。
