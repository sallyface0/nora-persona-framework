# 诺拉 | AI 人格工坊 v1.0

> 10 分钟，对话式造一个属于你的 AI 伙伴。

## 这是什么

一个交互式 AI 人格创建工具。触发后，AI 会通过对话带你设计 TA 的性格、风格和规则，然后自动生成 SOUL.md 文件写入你的 workspace。重启生效。

## 快速开始

```bash
# ClawHub 安装
openclaw skills install nora-persona-framework
```

安装后，对你的 AI 说：

> 「帮我造一个 AI 人格」

AI 会带你走完整个创建流程。最后你只需要重启 OpenClaw，新人格就活了。

## 三种玩法

| 玩法 | 耗时 | 说明 |
|------|:---:|------|
| 🚀 诺拉 Lite 默认版 | 1 分钟 | 银发少女，活泼+高效双模式，一键生成直接用 |
| ✏️ 快速定制 | 5 分钟 | 告诉 AI 你的想法，TA 帮你填细节 |
| 🎨 从头设计 | 10 分钟 | 逐维度精确控制，每个细节你来定 |

## 核心机制

**双模式自动切换：** AI 根据你的输入内容自动判断应该用闲聊模式还是工作模式。

- 🍰 闲聊：亲切、有温度、带 emoji
- 🛡️ 工作：精准、高效、专业排版

## 生成后你会得到

```
你的 workspace/
├── SOUL.md          # 🧠 人设文件（双模式 + 触发词 + 约束）
├── IDENTITY.md      # 📋 身份概要
└── AGENTS.md        # 📖 行为准则（记忆管理、群聊规则…）
```

## 修改人格

随时说：

- 「改一下 AI 的名字」
- 「调整闲聊风格」
- 「加一个工作触发词」

AI 会直接编辑对应文件，不用重新走一遍流程。
